Termo de Uso

Última atualização: versão 1.0

Este Termo de Uso regula o acesso e a utilização do sistema Room-Booking, destinado ao gerenciamento de reservas de salas de aula e auditórios da instituição de ensino.

1. Cadastro e acesso

O acesso ao sistema é restrito a administradores, professores/assessores e alunos previamente cadastrados pela instituição. Cada usuário é responsável por manter em sigilo suas credenciais de acesso (e-mail e senha).

2. Uso adequado

O sistema deve ser utilizado exclusivamente para fins de gerenciamento de reservas de espaços da instituição. É vedado o uso para fins diversos dos previstos, incluindo tentativas de acesso não autorizado a dados de outros usuários.

3. Responsabilidades

A instituição não se responsabiliza por reservas realizadas incorretamente por erro do próprio usuário, mas garante o registro e a rastreabilidade de todas as ações realizadas no sistema.

4. Alterações neste termo

Este termo pode ser atualizado periodicamente. Em caso de alteração relevante, será solicitado um novo aceite ao usuário.

Consulte também nossa Política de Privacidade
